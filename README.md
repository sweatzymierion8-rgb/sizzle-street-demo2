SIZZLE STREET — SAMPLE FOOD TRUCK WEBSITE
==========================================

What's included
- index.html: a complete responsive website with menu, about, schedule, and inquiry form
- No libraries or paid tools required

How to preview on iPhone
1. Download and unzip this folder if your iPhone supports it, or use a computer if available.
2. Tap index.html in Files. Some iOS previews may show the source instead of running it.
3. For the most reliable live preview, upload index.html to a free static host such as GitHub Pages (requires a GitHub account and setup), or use an online HTML editor that supports full-page preview.

Before showing it to a real client
- This is a fictional demo. Replace the brand name, logo, menu, prices, photos, hours, location, phone, email, and social links.
- The contact form opens an email app via mailto and does not save submissions. Replace hello@example.com with the client's real email.
- The weekly stops, prices, and contact details are placeholders, not real business information.
- Confirm rights to use all photos and use the client's own images whenever possible.

Selling your first website
- Offer a one-page site at an introductory $75–$150, with scope and revisions agreed in writing.
- Don't buy a domain or paid subscription out of pocket. The client can pay for any domain or premium features directly.
- Ask for a deposit before customizing, then the balance before final handoff.
